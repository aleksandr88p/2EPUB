
# 2EPUB

**2EPUB** — Python-приложение для создания двуязычных электронных книг с параллельным переводом.

Программа принимает две книги: английский оригинал и русский перевод, сопоставляет их тексты и создаёт один EPUB-файл.

В результирующей книге:

- **Английский текст выделен жирным.**
- Под ним расположен соответствующий русский перевод.
- Сохраняются порядок глав и структура английского оригинала.
- Книгу можно читать в обычной EPUB-читалке.

**Статус:** MVP v0.1 — рабочая экспериментальная версия.

## Установка и запуск

Инструкция для macOS. Понадобятся Git и Python (проект разрабатывался на Python 3.14).

### 1. Скачать проект

Откройте терминал и выполните:

```bash
git clone https://github.com/aleksandr88p/2EPUB.git
cd 2EPUB
```

### 2. Создать виртуальное окружение

```bash
python3 -m venv venv
```

Активировать его:

```bash
source venv/bin/activate
```

### 3. Установить зависимости

```bash
python -m pip install -r requirements.txt
```

При первой конвертации программа автоматически загрузит модель Qwen для сопоставления текстов. Для этого понадобится интернет.

### 4. Добавить книги

Положите английскую и русскую книги в формате `.fb2` в папку `books/`.

Например:

```text
2EPUB/
├── books/
│   ├── The Blade Itself.fb2
│   └── Кровь и железо.fb2
├── experiments/
├── output/
└── ...
```

Папку `books/` можно создать самостоятельно, если её нет.

Названия файлов могут быть любыми. Переименовывать книги не нужно.

### 5. Запустить конвертацию

В терминале, находясь в папке проекта с активированным виртуальным окружением, выполните:

```bash
python experiments/build_preview_epub.py \
  --en "books/The Blade Itself.fb2" \
  --ru "books/Кровь и железо.fb2" \
  --output "output/My Book.epub" \
  --all
```

Замените названия входных книг на свои.

**Что означают параметры:**

| Параметр | Описание |
|---|---|
| `--en` | Путь к английскому оригиналу |
| `--ru` | Путь к русскому переводу |
| `--output` | Путь и имя готовой EPUB-книги |
| `--all` | Обработать всю книгу, а не только первые две главы |

Пути с пробелами или русскими буквами заключайте в кавычки.

### 6. Забрать готовую книгу

После успешного завершения файл появится по указанному пути:

```text
output/My Book.epub
```

Его можно открыть в EPUB-читалке или перенести на электронную книгу.

### Дополнительные команды

Создать предварительную версию из первых двух сопоставленных глав:

```bash
python experiments/build_preview_epub.py \
  --en "books/The Blade Itself.fb2" \
  --ru "books/Кровь и железо.fb2" \
  --output "output/preview.epub"
```

Посмотреть все параметры:

```bash
python experiments/build_preview_epub.py --help
```

Запустить автоматические тесты:

```bash
python -m pytest
```

Если запустить скрипт без параметров, он попытается использовать стандартные тестовые книги из папки `books/`.

## Как работает 2EPUB

Программа выполняет несколько этапов обработки.

### 1. Чтение книг

С помощью Python и парсера FB2 извлекаются главы, абзацы и предложения.

Английский оригинал определяет структуру результирующей книги.

### 2. Сопоставление глав

Программа ищет соответствующие главы английской и русской книг.

Это необходимо, поскольку структура переводов иногда отличается от оригинала.

### 3. Создание эмбеддингов

Для предложений вычисляются мультиязычные эмбеддинги с помощью локальной модели **Qwen3-Embedding-0.6B**.

Эмбеддинги позволяют сравнивать смысл английских и русских предложений.

Результаты сохраняются в кеш, чтобы при повторных экспериментах не вычислять их заново.

### 4. Сопоставление предложений

Алгоритм динамического программирования подбирает последовательность соответствий между оригиналом и переводом.

Поддерживаются варианты:

- `1:1` — одно предложение соответствует одному.
- `1:2` — одно предложение соответствует двум.
- `2:1` — два предложения соответствуют одному.
- `skip_en` и `skip_ru` — пропуски, когда прямое соответствие не найдено.

### 5. Восстановление абзацев

После сопоставления предложений программа восстанавливает двуязычные абзацы с опорой на структуру английской книги.

### 6. Создание EPUB

С помощью EbookLib формируется итоговый EPUB, содержащий английский текст и русский перевод.

## Технологии

| Технология | Назначение |
|---|---|
| Python | Основной язык разработки |
| EbookLib | Создание EPUB |
| BeautifulSoup | Разбор структуры электронных книг |
| Qwen3-Embedding-0.6B | Мультиязычные эмбеддинги |
| NumPy | Работа с числовыми данными |
| Динамическое программирование | Сопоставление текстов |
| pytest | Автоматическое тестирование |

Модель эмбеддингов запускается локально. После первоначальной загрузки для её работы не требуется облачный API.

## Текущее состояние проекта

### Что уже реализовано

- Чтение и обработка FB2-книг.
- Сопоставление английских и русских глав.
- Создание и кеширование эмбеддингов.
- Сопоставление предложений и их групп.
- Восстановление двуязычных абзацев.
- Генерация EPUB.
- Проверки структуры и полноты результата.
- CLI с произвольными путями к входным и выходному файлам.
- Автоматические тесты.

### Что проверено

Первая экспериментальная книга — **The Blade Itself / «Кровь и железо»**.

Получен полный двуязычный EPUB. Проверки структуры и сохранности текста выполнены, а независимая частичная проверка сопоставления обнаружила несколько ошибок на границах абзацев.

Это подтверждает работоспособность конвейера, но не гарантирует идеального сопоставления.

### Известные ограничения

- Конвертер принимает на вход только FB2.
- Возможны ошибки сопоставления соседних абзацев, особенно коротких реплик.
- Не всё исходное форматирование сохраняется идеально, в частности курсив и переносы стихотворных строк.
- Разные переводы могут заметно отличаться от оригинала по структуре.
- Проверка результата не гарантирует полного смыслового соответствия всех абзацев.
- Качество на других книгах пока недостаточно исследовано.

**Важно:** MVP предназначен для экспериментов и личного использования. Результат рекомендуется проверять.

## Структура проекта

```text
2EPUB/
├── bookparse/       # Парсинг и обработка книг
├── experiments/     # Скрипты экспериментов и сборки EPUB
├── tests/           # Автоматические тесты
├── docs/            # Техническая документация
├── books/           # Входные книги
├── cache/           # Модель и кеш эмбеддингов
├── output/          # Готовые EPUB
├── requirements.txt
├── README.md
└── README.ru.md
```

Папки `books/`, `cache/` и `output/` исключены из Git. Книги, модели и результаты конвертации не загружаются в репозиторий.

Подробности реализации: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Разработка

Основная разработка ведётся на Python с использованием AI IDE Windsurf.

Принципы проекта:

- Английский оригинал определяет структуру итоговой книги.
- Не терять и не дублировать текст оригинала и перевода.
- Разделять парсинг, сопоставление и генерацию EPUB.
- Кешировать эмбеддинги для ускорения экспериментов.
- Проверять качество результата автоматическими тестами и независимым анализом.

Текущая версия — экспериментальный MVP, а не законченный коммерческий продукт.
