# 2EPUB

[English](README.md) | [Русский](README.ru.md)

2EPUB — экспериментальный Python CLI, который создаёт двуязычную EPUB-книгу
из оригинала и его перевода. Оригинал задаёт порядок глав и структуру
абзацев; его текст выделяется жирным, а соответствующий перевод идёт сразу
под ним.

## Возможности

- EPUB и FB2 в любой комбинации: EPUB+EPUB, EPUB+FB2, FB2+EPUB или FB2+FB2.
- Английский, русский и испанский во всех шести направлениях: EN→RU,
  RU→EN, EN→ES, ES→EN, RU→ES и ES→RU.
- Автоопределение языка по метаданным и ручные параметры `--source-lang`
  и `--translation-lang`.
- Сохраняются распознанная структура исходной книги и поддерживаемое
  блочное оформление; при наличии переносятся её обложка и изображения.
  Для результата создаются навигация EPUB и оглавление.
- Для FB2 с одной секцией fallback может восстановить повторяющуюся
  структуру частей и глав; при недостаточной уверенности границы не
  применяются, а выводится предупреждение.
- Необязательный `--short-paragraphs` ориентируется примерно на 35–40 слов
  оригинала в блоке. Перевод сохраняется целиком без ограничения длины;
  разбиение выполняется только между предложениями и операциями
  сопоставления, группы 1:2 и 2:1 целиком.

## Требования и установка

Проверенная версия Python — 3.14. Команды ниже предназначены для macOS/Linux.
При первом использовании `build` требуется интернет для загрузки локальной
модели эмбеддингов Qwen.

```bash
git clone https://github.com/aleksandr88p/2EPUB.git
cd 2EPUB
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
```

Модель хранится в `cache/models/`, эмбеддинги предложений — в
`cache/embeddings/`; последующие сборки повторно используют кеш.

## Быстрый старт

Поместите книги в `books/` или укажите путь к ним в другом месте. Первый
аргумент — оригинал, второй — перевод.

```bash
python -m bookparse check "books/original.epub" "books/translation.fb2"
python -m bookparse build "books/original.epub" "books/translation.fb2" \
  --short-paragraphs --output "output/bilingual.epub"
```

По умолчанию создаётся полная книга; путь по умолчанию —
`output/2epub.epub`. Параметр `--preview` ограничивает сборку первыми двумя
сопоставленными парами глав. Папка результата создаётся автоматически.

Языки берутся из метаданных. Если они отсутствуют или неверны, задайте оба
параметра:

```bash
python -m bookparse build "books/original.epub" "books/перевод.fb2" \
  --source-lang es --translation-lang ru
```

Поддерживаются коды `en`/`eng`, `ru`/`rus`, `es`/`spa` и региональные коды,
например `es-ES`. Если метаданных нет, используется прежний запасной вариант
EN→RU.

## Команды CLI

Для каждой входной книги можно независимо выбрать EPUB или FB2.

| Команда | Назначение | Пример |
|---|---|---|
| `check SOURCE TRANSLATION` | Проверить книги и вывести предупреждения/ошибки. `--output PATH` сохраняет отчёт. | `python -m bookparse check source.epub translation.fb2` |
| `build SOURCE TRANSLATION` | Собрать двуязычный EPUB. Есть `--preview`, `--short-paragraphs`, `--output PATH` и языковые параметры. | `python -m bookparse build source.epub translation.fb2 --preview` |
| `align-chapters SOURCE TRANSLATION` | Сопоставить главы и сохранить JSON; `--output PATH` меняет путь. | `python -m bookparse align-chapters source.epub translation.fb2` |
| `parse BOOK` | Сохранить структуру одной книги в JSON; доступны `--output PATH` и `--lang CODE` (`en`, `ru` или `es`). | `python -m bookparse parse source.epub --output cache/source.json` |

Справка: `python -m bookparse --help` или
`python -m bookparse build --help`.

## Ограничения

- Поддерживаются только английский, русский и испанский. Сегментация
  предложений и смысловое сопоставление эвристические; проверяйте отчёт
  и готовую книгу.
- Сопоставляются главы основного текста с заголовками; объединение глав
  не поддерживается. Главы перевода без пары в оригинале не попадают
  в результат.
- Структура абзацев перевода заменяется структурой оригинала. Часть
  встроенного оформления, например курсив, упрощается.
- `--short-paragraphs` не разрывает группы сопоставления, операции,
  пересекающие исходные абзацы, или структурные блоки. Поэтому отдельный
  неделимый блок может превышать 40 слов оригинала.
- Проверка сравнивает EPUB с текстом, извлечённым парсером. Она не находит
  потери, случившиеся при парсинге, и не оценивает смысл перевода.
