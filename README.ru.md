# 2EPUB

[English](README.md) | [Русский](README.ru.md)

**2EPUB создаёт двуязычную EPUB-книгу из исходной книги и её перевода.** Первая книга задаёт порядок глав и структуру абзацев; её текст отображается жирным, а соответствующий текст перевода — сразу под ним обычным шрифтом.

В MVP поддерживаются английский (`en`), русский (`ru`) и испанский (`es`) во всех шести направлениях: EN→RU, RU→EN, EN→ES, ES→EN, RU→ES и ES→RU.

**Статус:** экспериментальный MVP v0.1. Конвертер работает на реальных книгах, но не гарантирует идеального смыслового сопоставления.

## Быстрый старт (macOS)

Проект разработан и проверен на Python 3.14. Понадобятся Git и подключение к интернету для первой загрузки модели.

Склонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/aleksandr88p/2EPUB.git
cd 2EPUB
```

Создайте и активируйте виртуальное окружение, затем установите зависимости:

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
```

При первом запуске `build` автоматически скачает модель Qwen3-Embedding-0.6B. Она сохраняется в `cache/models/`, а эмбеддинги предложений — в `cache/embeddings/`. Первая полная конвертация может занять время; при повторной обработке кешированные эмбеддинги используются повторно.

## Подготовка книг

При желании положите книги в `books/`. Папка сохраняется в Git с помощью `.gitkeep`, но файлы книг игнорируются и не попадают в коммиты. Также можно указать файлы из любого другого места.

Для исходной книги и перевода независимо поддерживаются FB2 и EPUB. Направления языков:

| Исходная книга | Перевод |
|---|---|---|
| Английский | Русский |
| Русский | Английский |
| Английский | Испанский |
| Испанский | Английский |
| Русский | Испанский |
| Испанский | Русский |

Первый путь всегда относится к оригиналу, второй — к переводу. По умолчанию 2EPUB определяет язык по метаданным EPUB/FB2. Если метаданные отсутствуют или неверны, задайте `--source-lang` и `--translation-lang`. Принимаются коды и псевдонимы `en`/`eng`, `ru`/`rus`, `es`/`spa`, а также региональные коды, например `es-ES`. Если метаданных нет, для совместимости используется EN→RU. Неподдерживаемые коды вызывают понятную ошибку. Пути с пробелами и кириллицей заключайте в кавычки.

Примеры всех направлений (каждый файл может быть FB2 или EPUB):

```bash
python -m bookparse build books/english.fb2 books/russian.epub
python -m bookparse build books/russian.fb2 books/english.epub
python -m bookparse build books/english.fb2 books/spanish.epub
python -m bookparse build books/spanish.epub books/english.fb2
python -m bookparse build books/russian.epub books/spanish.fb2
python -m bookparse build books/spanish.fb2 books/russian.epub
```

## Обычный порядок работы

Сначала проверьте исходные книги:

```bash
python -m bookparse check \
  "books/Lost_Gods_-_Brom.epub" \
  "books/потерянные боги Бром.fb2"
```

Затем создайте полную двуязычную книгу:

```bash
python -m bookparse build \
  "books/Lost_Gods_-_Brom.epub" \
  "books/потерянные боги Бром.fb2"
```

По умолчанию EPUB сохраняется в `output/2epub.epub`. Папка `output/` будет создана автоматически, если её ещё нет.

Чтобы создать предварительную версию из первых двух сопоставленных пар глав:

```bash
python -m bookparse build \
  "books/Lost_Gods_-_Brom.epub" \
  "books/потерянные боги Бром.fb2" \
  --preview
```

Чтобы задать другое имя или расположение результата:

```bash
python -m bookparse build \
  "books/Lost_Gods_-_Brom.epub" \
  "books/потерянные боги Бром.fb2" \
  --output "output/Lost_Gods_bilingual.epub"
```

Откройте полученный `.epub` в обычной читалке или перенесите на электронное устройство. Папка `output/` игнорируется Git.

## Справочник CLI

Для обычного использования достаточно команд `check` и `build`. Ниже во всех командах входные пути могут указывать на `.fb2` или `.epub`; исключение — команда `parse`, которая принимает одну книгу за раз.

### `check SOURCE TRANSLATION`

Проверяет исходные книги и выводит отчёт перед конвертацией. Необязательный параметр `-o/--output PATH` сохраняет отчёт в текстовый файл.

```bash
python -m bookparse check "books/english.epub" "books/russian.fb2"
python -m bookparse check "books/english.epub" "books/russian.fb2" \
  --output "output/preflight.txt"
python -m bookparse check "books/spanish.epub" "books/russian.fb2" \
  --source-lang es --translation-lang ru
```

`build` запускает такую же проверку автоматически. Отдельный `check` полезен, если нужно заранее прочитать предупреждения источника.

### `build SOURCE TRANSLATION`

По умолчанию создаёт полную двуязычную книгу. Добавьте `--preview`, чтобы обработать только первые две сопоставленные пары глав. Необязательный `-o/--output PATH` задаёт путь к файлу; по умолчанию используется `output/2epub.epub`.

```bash
python -m bookparse build "books/english.fb2" "books/russian.epub"
python -m bookparse build "books/spanish.epub" "books/english.fb2"
python -m bookparse build "books/english.fb2" "books/russian.epub" --preview
python -m bookparse build "books/english.fb2" "books/russian.epub" \
  --output "output/My_Bilingual_Book.epub"
python -m bookparse build "books/spanish.fb2" "books/russian.epub" \
  --source-lang es --translation-lang ru
```

Для каждой книги отдельно можно выбрать FB2 или EPUB, в том числе смешать форматы. Структуру задаёт оригинал. Его обложка и используемые изображения переносятся в результат, если они есть. Языковые параметры необязательны, если метаданные книг заполнены верно.

### `align-chapters SOURCE TRANSLATION`

Сопоставляет главы и сохраняет JSON-отчёт. Это диагностическая команда; EPUB она не создаёт. Необязательный `-o/--output PATH` меняет путь отчёта. По умолчанию файл сохраняется как `cache/align_<en>--<ru>.json`.

```bash
python -m bookparse align-chapters "books/english.epub" "books/russian.fb2"
python -m bookparse align-chapters "books/english.epub" "books/russian.fb2" \
  --output "output/chapter_alignment.json"
python -m bookparse align-chapters "books/spanish.epub" "books/english.fb2" \
  --source-lang es --translation-lang en
```

### `parse BOOK`

Разбирает одну EPUB- или FB2-книгу и сохраняет извлечённую структуру в JSON. По умолчанию файл записывается в `cache/<имя-книги>.json`. Параметр `-o/--output PATH` меняет путь; `--lang LANG` задаёт язык сегментации (`en`, `ru` или `es`).

```bash
python -m bookparse parse "books/english.epub"
python -m bookparse parse "books/spanish.fb2" --lang es \
  --output "cache/spanish_structure.json"
```

### Справка и тесты

```bash
python -m bookparse --help
python -m bookparse build --help
python -m pytest
```

## Как читать отчёты

### `check`

В отчёте указаны уровни проблем и общий вердикт:

- `INFO` — справочная информация, не блокирует конвертацию.
- `WARNING` — особенность источника, способная повлиять на качество; её стоит проверить. Сборка продолжается.
- `ERROR` — проблема, которую текущие проверки считают критической.
- `VERDICT: OK` — предупреждений и ошибок не найдено (информационные сообщения при этом возможны).
- `VERDICT: PROCEED WITH CAUTION` — найдены предупреждения; проверьте их, прежде чем полагаться на результат.
- `VERDICT: STOP` — найдена ошибка. `build` останавливается до сопоставления и возвращает ненулевой код.

Проверки эвристические. Предупреждение может оказаться ложным срабатыванием, а `OK` не означает, что перевод прошёл смысловую проверку.

### `align-chapters`

- **Paired** — выбранные пары глав.
- **Confident / doubtful** — оценки качества пар по структурным признакам; они не доказывают смысловую точность.
- **Unmatched** — главы основного текста с заголовками, для которых не нашлась пара.
- **Service sections** — безымянное начало или служебные части, например примечания; они перечисляются отдельно от сопоставления глав основного текста.
- **Word coverage** — доля слов оригинала и перевода в сопоставленных главах; подписи отчёта соответствуют определённым или явно заданным языкам.

### `build`

- **`Pair`** — главы оригинала и перевода, обрабатываемые вместе и подписанные названиями языков.
- **Только оригинал** (в логе, например, `Spanish-only`) — глава без пары в переводе; она сохраняется без выдуманного текста.
- **`embeddings`** — число новых векторов предложений и объединённых фрагментов; остальные взяты из кеша.
- **`ops`** — количество операций сопоставления предложений (`1:1`, `1:2`, `2:1`, `skip_en`, `skip_ru`) и оценки качества сопоставленных групп.
- **`[OK]` / `[FAIL]`** — проверки собранного EPUB: набор и порядок глав, XHTML, полнота и порядок текста относительно парсера, внутренние ссылки изображений. При провале команда возвращает ненулевой код и не сообщает об успешной конвертации.
- **`TOTAL`** — количество глав и предложений, глав только из оригинала и абзацев оригинала без перевода. Главы перевода, не вошедшие в структуру оригинала, перечисляются отдельно.

Названия операций `skip_en` и `skip_ru` сохранены для совместимости; они означают пропуск предложения в оригинале или переводе соответственно. Проверка сохранности текста сравнивает EPUB с извлечённым парсером текстом. Она не может доказать, что каждое предложение перевода правильно соответствует исходному тексту над ним.

## Проверенные конвертации

| Книга | Входные форматы | Результат |
|---|---|---|
| *The Blade Itself* / «Кровь и железо» | FB2 + FB2 | Создан полный EPUB: 52 XHTML-раздела, 48 сопоставленных пар глав и 4 главы только из оригинала. Структурные проверки и проверки текста прошли. |
| *Lost Gods* | EPUB + FB2 | Полный EPUB создан с настоящей моделью Qwen: 116 XHTML-разделов, 110 сопоставленных пар и 6 глав только из оригинала. Проверки структуры, текста и ссылок на изображения прошли. |

Для `Lost Gods` предварительная проверка выдала `PROCEED WITH CAUTION` из-за предупреждений об исходниках и структуре глав; сборка и последующие проверки всё равно завершились успешно. Сопоставление глав включало одну doubtful-пару. Эти результаты относятся к конкретным книгам и не характеризуют универсальную точность.

## Ограничения

- Смысловое сопоставление экспериментальное. Перевод может оказаться под соседним абзацем оригинала, особенно для коротких реплик, отдельных строк, писем и эпиграфов.
- `skip_en` и `skip_ru` — операции сопоставления, а не смысловые оценки. Если их много, результат стоит проверить.
- Структура абзацев перевода не восстанавливается: она следует исходной книге. Строки стихов могут объединяться.
- Некоторые элементы оформления, в том числе встроенный курсив, парсеры упрощают до обычного текста.
- Для английского, русского и испанского есть языковые правила сегментации предложений, но сегментация остаётся эвристической: редкие сокращения и знаки препинания могут обрабатываться неверно.
- В MVP не поддерживаются языки помимо английского, русского и испанского, даже несмотря на мультиязычность модели Qwen.
- Автоматические проверки сверяют структуру и текст с результатом парсинга. Они не подтверждают смысл или литературное качество перевода и не обнаруживают текст, потерянный ещё при парсинге.
- Главы перевода без соответствия структуре оригинала перечисляются в отчёте, но в итоговую книгу не добавляются.

MVP v0.1 — рабочий конвертер, а не гарантия идеального сопоставления. Перед внимательным чтением проверьте полученный EPUB.

## Структура проекта

```text
2EPUB/
├── bookparse/       # Парсеры, CLI, проверки, сопоставление и сборка абзацев
├── experiments/     # EPUB-сборщик и диагностические скрипты
├── tests/           # Автоматические тесты, включая end-to-end сценарии CLI
├── docs/            # Заметки об архитектуре
├── books/           # Входные книги пользователя (игнорируются Git)
├── cache/           # Веса модели и кеш эмбеддингов (игнорируются Git)
├── output/          # Готовые EPUB и отчёты (игнорируются Git)
├── requirements.txt
├── README.md
└── README.ru.md
```

Описание реализации: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Личные книги, файлы модели и сгенерированные результаты не добавляются в репозиторий.

## Дальнейшее развитие

Возможные улучшения конвертера: повысить качество сопоставления, лучше сохранять форматирование и расширить QA на другие книги. Будущее отдельное приложение для чтения — план, а не реализованная функция; оно может включать веб-читалку, управление параллельным текстом, необязательный перевод через LLM и адаптацию сложности текста.
